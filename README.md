# MY Bharat Design System

A reusable React component library built with TypeScript, CSS Modules, and design tokens.

The design system follows an Atomic Design architecture and provides reusable components for building consistent MY Bharat user interfaces.

## Features

- Reusable React components built using Atomic Design.
- TypeScript support with bundled declaration files.
- CSS Modules for component-level styling.
- Centralized design tokens and CSS custom properties.
- Configurable primary and secondary theme colors.
- Configurable container width.
- Interactive Storybook documentation.
- React 18 and React 19 compatibility.
- Vite and Next.js support.
- CLI-based theme configuration.

---

## Installation

Install the package using npm:

```bash
npm install @mybharatyouth/design-system
```

React and ReactDOM are peer dependencies and must be provided by the consuming application.

---

## Usage

Import the components you need and the design system stylesheet:

```tsx
import {
  Button,
  Header,
  Text,
} from "@mybharatyouth/design-system";

import "@mybharatyouth/design-system/styles.css";

export function Example() {
  return (
    <>
      <Header />

      <Text>Welcome to MY Bharat</Text>

      <Button label="Continue" />
    </>
  );
}
```

The package can be used with both React and Next.js applications.

Components that use browser APIs or interactive behavior should be rendered from a Client Component when required by Next.js.

## Theme Configuration CLI

MY Bharat Design System provides a CLI to configure theme settings for your application.

The CLI allows developers to customize:

- Primary color
- Secondary color
- Container width

### Step 1: Install the Package

```bash
npm install @mybharatyouth/design-system
```

### Step 2: Initialize Theme Configuration

Run the following command from your application root:

```bash
npx mybharat-design-system init
```

The interactive CLI prompts you to configure your theme.

### Step 3: Configure Theme Values

You can provide your preferred HEX colors:

```text
MY Bharat Design System Setup

Enter your Primary Color: #BC4717
Enter your Secondary Color: #2563EB

Select Container Width:
  960px - Small
  1140px - Medium
  1200px - Large
  1320px - Extra Large
```

The CLI validates HEX color inputs and provides default theme values.

### Step 4: Generated Files

After successful configuration, the CLI generates two files in your application root.

**1. mybharat.config.json**

Stores your theme configuration:

```json
{
  "theme": {
    "primary": "#BC4717",
    "secondary": "#2563EB"
  },
  "container": {
    "width": "1200px"
  }
}
```

**2. mybharat-theme.css**

Contains the corresponding CSS custom property overrides:

```css
/* Generated by MY Bharat Design System CLI */

:root {
  --color-primary: #BC4717;
  --color-secondary: #2563EB;
  --size-container-lg: 1200px;
}
```

### Step 5: Import Theme Styles

Import the design system stylesheet first, followed by the generated theme stylesheet.

```tsx
import "@mybharatyouth/design-system/styles.css";
import "../mybharat-theme.css";
```

This ensures your custom theme values override the default design system tokens.

Import both stylesheets once in your application's global entry point.

### Framework Integration

The CLI detects the application framework and displays relevant integration instructions.

**Vite / React**

Import both stylesheets in:

```text
src/main.jsx
```

or:

```text
src/main.tsx
```

**Next.js**

Import both stylesheets in:

```text
app/layout.js
```

or:

```text
app/layout.tsx
```

**Other React applications**

Import both stylesheets in your application's global stylesheet entry point.

### Updating Existing Theme Configuration

You can run the CLI again whenever you want to update your theme:

```bash
npx mybharat-design-system init
```

If existing MY Bharat theme files are detected, the CLI asks whether you want to update them.

- Selecting **Yes** allows you to update the theme using your existing values as defaults.
- Selecting **No** preserves your existing files without changes.

### Supported Configuration Options

| Configuration | Available options |
|---|---|
| Primary color | Custom HEX color |
| Secondary color | Custom HEX color |
| Container width | 960px, 1140px, 1200px, 1320px |

## Font Configuration

The design system uses **Noto Sans** as the default font family.

The font family is configured through the following CSS custom property:

```css
--font-family-base
```

The design system supports both standard React applications and Next.js applications.

### Standard React Application

The design system defines Noto Sans as the preferred font family.

For the font to render correctly, ensure that Noto Sans is loaded in your application.

#### Step 1: Load Noto Sans

Add the following to your application's global stylesheet:

```css
@import url("https://fonts.googleapis.com/css2?family=Noto+Sans:ital,wght@0,100..900;1,100..900&display=swap");
```

For example:

```css
/* src/index.css */

@import url("https://fonts.googleapis.com/css2?family=Noto+Sans:ital,wght@0,100..900;1,100..900&display=swap");
```

#### Step 2: Import the Design System Stylesheet

```tsx
import "@mybharatyouth/design-system/styles.css";
```

The design system will use Noto Sans when it is available.

### Next.js

For Next.js applications, it is recommended to use `next/font/google`.

This allows Next.js to optimize and self-host the font.

#### Step 1: Install the Package

```bash
npm install @mybharatyouth/design-system
```

#### Step 2: Import Noto Sans

In your `app/layout.tsx` file:

```tsx
import { Noto_Sans } from "next/font/google";

import "@mybharatyouth/design-system/styles.css";
```

#### Step 3: Configure the Font

```tsx
const notoSans = Noto_Sans({
  subsets: ["latin"],
  display: "swap",
  variable: "--font-noto-sans",
});
```

The `variable` option exposes the font as a CSS custom property that can be used by the design system.

#### Step 4: Apply the Font Variable

Apply the generated font variable to the `<html>` element:

```tsx
<html
  lang="en"
  className={`${notoSans.variable} h-full antialiased`}
>
```

#### Complete Next.js Example

Your `app/layout.tsx` can look like this:

```tsx
import type { Metadata } from "next";
import { Noto_Sans } from "next/font/google";

import "@mybharatyouth/design-system/styles.css";

const notoSans = Noto_Sans({
  subsets: ["latin"],
  display: "swap",
  variable: "--font-noto-sans",
});

export const metadata: Metadata = {
  title: "MY Bharat Application",
  description: "Built using MY Bharat Design System",
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html
      lang="en"
      className={`${notoSans.variable} h-full antialiased`}
    >
      <body>{children}</body>
    </html>
  );
}
```

Interactive components that use browser APIs or React hooks should be rendered from a Client Component when required by Next.js.

## Design System Architecture

The project follows the Atomic Design methodology:

```text
Atoms
  ↓
Molecules
  ↓
Organisms

Primitives / Layout
  ↓
Application UI
```

The components are designed to be composable and reusable across MY Bharat applications.

---

## Design Tokens

The design system uses CSS custom properties for shared design tokens such as:

- Colors
- Typography
- Spacing
- Border radius
- Shadows
- Sizes
- Breakpoints

These tokens are included automatically through the bundled design system stylesheet.

The CLI provides a convenient way to override selected theme tokens without modifying the package source code.
